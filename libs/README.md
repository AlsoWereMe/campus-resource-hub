# libs/

各服务共用的 Python 包，也是 uv 工作区成员。

| 目录 | 用途 |
| --- | --- |
| `common/` | 非业务公共库：统一错误结构、traceId 与日志、配置、可注入时钟、JWT 验签与权限点校验、数据库会话、Outbox、消息收发与定时任务工具 |

## 规则

- **不放业务逻辑**。任何只属于某个模块的规则、模型、状态机都留在该模块的服务里。
- 公共库被所有服务依赖，修改须组内评审（任务书「质量门禁」），并保持向后兼容；不兼容的修改须在提交说明中标注 `BREAKING CHANGE`。
- 公共库的公开函数与类必须有类型标注，并通过 mypy strict。
